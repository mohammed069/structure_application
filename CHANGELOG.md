# Changelog

All notable changes to this Flutter starter will be documented in this file.

## 1.0.0

- Initial Flutter starter template.
- Added Clean Architecture-oriented project structure.
- Added Dio API abstraction and exception handling.
- Added GetIt dependency injection.
- Added GoRouter navigation.
- Added BLoC/Cubit support.
- Added localization support with Easy Localization.
- Added theme and reusable UI foundations.
- Added local cache support.
- Added network connectivity abstraction.
- Added Flutter linting configuration.
